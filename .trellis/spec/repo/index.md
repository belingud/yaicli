# Repository Conventions — Index

Cross-cutting rules for the repository as a whole: task runner, commits, docs, versioning, release
and Trellis. Language-specific rules live in [../py/index.md](../py/index.md).

## Pre-Development Checklist

1. Read this file if you touch `Justfile`, `.github/`, `pyproject.toml`, `.bumpversion.cfg`,
   `cliff.toml`, `mkdocs.yml`, `README.md`, `docs/`, `openspec/`, or a version string. Then read
   [build-and-release.md](./build-and-release.md).
2. Confirm which layer you are changing and open [../py/index.md](../py/index.md) first.
3. Skim the shared thinking guides: [../guides/index.md](../guides/index.md).

## Ground Rules

- **Conventional Commits are mandatory.** `cliff.toml` maps prefixes (`feat`, `fix`, `perf`,
  `refactor`, `docs`, `test`, `chore`, ...) into `CHANGELOG.md` groups and
  `filter_unconventional = true` drops non-conventional subjects. Recent history uses scoped
  subjects, e.g. `feat(functions): ...`, `feat(filesystem): ...`, `perf(mcp): ...`, `docs: ...`.
  Breaking changes use `!` (e.g. `feat!: confirm tool calls before execution`) and get a
  `[**breaking**]` marker in the changelog.
- **Documentation ships with the change.** User-visible behavior updates `README.md` and the
  matching `docs/` page. New doc pages must also be added to the `nav:` in `mkdocs.yml`, otherwise
  they are unreachable on the docs site.
- **`AGENTS.md` is a symlink to `CLAUDE.md`.** Never write `AGENTS.md` separately; edit `CLAUDE.md`.
  The `<!-- TRELLIS:START -->` / `<!-- TRELLIS:END -->` block at the bottom is managed by
  `trellis update` — keep edits outside it.
- **Trellis files are committed** except what `.trellis/.gitignore` excludes (`.developer`,
  `.current-task`, `.runtime/`, agent logs, `__pycache__`). `.claude/`, `.dsh/`, `.agents/` are the
  platform surfaces and are committed too.
- **Task artifacts are the plan of record.** Non-trivial work follows `.trellis/workflow.md`:
  planning artifacts (`prd.md`, and `design.md`/`implement.md` for complex tasks) before code,
  spec update before commit. Feature-level specs live in `openspec/specs/`, proposals/archives in
  `openspec/changes/`.
- **Generated artifacts stay out of git**: `dist/`, `build/`, `.venv/`, `.coverage*`, `.pytest_cache/`,
  `.ruff_cache/`, `__pycache__/`, `.tox/`, `.pdm-build/` (root `.gitignore`; `Justfile clean` still
  removes the stale `.pdm_build/` spelling). `CHANGELOG.md` is generated by `git cliff` — do not
  hand-edit release sections.

## Documentation Map

| File / Directory | Audience | Update when |
| --- | --- | --- |
| `README.md` | Users (PyPI/GitHub landing) | user-visible features, flags, config keys, providers, install |
| `docs/` + `mkdocs.yml` nav | Users (docs site) | feature usage pages; keep `nav:` in sync |
| `docs/providers/*.md` | Users + maintainers | provider support matrix, models, provider-specific quirks |
| `docs/dev/` (`architecture.md`, `add-provider.md`, `debug-cli.md`) | Contributors | internal architecture, provider tutorial, CLI debugging |
| `CHANGELOG.md` | Users | generated by `just changelog` (git-cliff), not by hand; `docs/changelog.md` is a stale historical copy (stops at v0.7.8) |
| `CLAUDE.md` (↔ `AGENTS.md`) | AI agents | architecture, commands, conventions |
| `openspec/specs/` | Maintainers + AI agents | current behavior specs (tool confirmation, interactive tool policy, DeepSeek thinking mode) |
| `openspec/changes/` (+ `archive/`) | Maintainers | spec-driven change proposals and their archived history |
| `plans/` | Maintainers | ad-hoc implementation plans (`01-exclude-params-feature.md`, ...) |
| `.trellis/spec/**` | AI agents | coding standards (this directory) |

## Task Runner

`just` is the local task runner (`just --list`). CI does not depend on it, so commands must remain
runnable directly as documented in [build-and-release.md](./build-and-release.md).

## Trellis Workflow

- Start a session with the `trellis-start` skill (DSH) or the project `CLAUDE.md` block; the
  canonical workflow is `.trellis/workflow.md`.
- Current state: `python3 ./.trellis/scripts/get_context.py`
  (add `--mode phase`, `--mode packages`, `--mode record` for other views).
- Task lifecycle: `python3 ./.trellis/scripts/task.py {create,start,current,finish,archive,list}`.
- Session journal: `python3 ./.trellis/scripts/add_session.py --title ... --commit <hash> --summary ...`.
- Before coding in a layer, read its `.trellis/spec/` index (see `../py/index.md`); update the spec
  when a fix reveals a rule worth keeping.
- Platforms configured in this repo: Claude Code (`.claude/`: hooks, agents, slash commands, skills and
  `settings.json` hook wiring) and DeepSeek Harness / dsh (`.dsh/skills/`, pull-based: load
  `trellis-start` / `trellis-continue` / `trellis-finish-work` on demand). `.agents/skills/` is the
  platform-neutral Trellis skill catalog shared by agent tools; `.codex/skills/` holds the older
  OpenSpec skills for Codex.
